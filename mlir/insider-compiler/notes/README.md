[校订正文总目录](../README.md) · [读前导读](../guide/README.md) · [跨章知识串联](cross-chapter.md) · [脚注与参考资料](../inside-compiler-refs.md)

这套笔记用于读后复习和查找机制：保留每章关键概念、公式、接口、算法步骤及成立条件。内容按知识关系重新组织，重要条目注明原章小节，详细论证和完整清单仍可回到校订正文阅读。

本套材料沿用 LLVM/MLIR **18.1.8** 的校订基准。第13章以固定 Triton 提交 `47fc046ff29c9ea2ee90e987c39628a540603c8f` 为准，附录明确区分本地实现与较新概念。接口列表是源码阅读入口；示意公式和短代码不构成新增的端到端运行验证。

## 按问题查找

| 遇到的问题 | 优先查阅 | 需要连起来的机制 |
| --- | --- | --- |
| 操作定义正确，但通用优化不处理它 | 3、4、7 | 注册定义、能力接口、副作用与算法适用条件 |
| 改写返回成功，IR 后续仍失败 | 5、6、10 | Rewriter 通知、转换合法性、类型桥接、Pass 顺序 |
| 张量程序产生了大量复制或分配 | 9、10、11 | 读写冲突、存储复用、释放责任、调用边界 |
| 分块或融合改变数值结果 | 1、9、14、15 | 初始化与浮点次序、访问依赖、整数约束 |
| GPU 上数据正确但速度很差 | 9、11、13 | 向量与布局、访存事务、共享内存、同步和寄存器成本 |
| 变换脚本中的目标句柄失效 | 4、6、12 | 接口契约、操作替换、句柄与负载 IR 状态 |
| 求解器返回有理解，但循环不存在合法整数点 | 14、15 | 松弛、整数样本、存在量化与整除信息 |
| 分片、量化或异步元数据没有带来预期行为 | 附录、4、8、11 | 元数据消费者、实际转换、运行时和目标支持 |

复习时可以先尝试口头说明“输入是什么、维持什么条件、怎样计算或改写、失败意味着什么”，再查看具体接口。只记接口名，容易把算法契约与某个版本的实现细节混在一起。
