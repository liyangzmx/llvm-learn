# 第 13 章核查与实验记录

正文以 LLVM 18.1.8 接口为准，重新组织为目标契约、各阶段适配、描述生成和 BPF 闭环。原书和初版静态修订的历史材料保存在 origin 与提交 `c5924c6`。

| 主题 | 源码 / 实验依据 | 处理 |
| --- | --- | --- |
| 指令选择与合法化 | BPFISelLowering.cpp、BPFISelDAGToDAG.cpp；backend.ll 的 finalize-isel 输出 | 区分公共框架与目标钩子，检查 ADD_rr；不把 DAG 结构节点逐个当作机器指令 |
| 寄存器与约束 | BPFRegisterInfo.cpp、BPFInstrInfo.cpp、BPFCallingConv.td | 补齐保留寄存器、别名、CSR/mask、复制、spill/reload、scavenging；R11 是伪寄存器 |
| 帧索引与 ABI | BPFFrameLowering.cpp、BPFRegisterInfo.cpp；volatile 栈对象和六参数负例 | 8 字节对象落到 r10-8；六参数用例报 stack arguments are not supported，不从 TD 后备规则推断支持栈参数 |
| MC 与对象 | BPFMCCodeEmitter.cpp、BPFELFObjectWriter.cpp、BPFAsmBackend.cpp | 对同输入生成 bpfel/bpfeb，检查 EM_BPF、端序、external/R_BPF_64_32 及反汇编 |
| 独立描述文件 | experiments/ch13/Book.td；五种 llvm-tblgen 生成器与 JSON 记录 | 完整可解析 TD，验证 add r1,r2,r3 对应记录位域 0x16c0；不声称 Book 已注册为可用 llc 后端 |
| 清单 13-1 / 注册 | TargetSelect.h、llvm-c/Target.h、BPFTargetInfo.cpp、BPFTargetMachine.cpp、BPFMCTargetDesc.cpp | 按 TargetInfo、Target、TargetMC、AsmPrinter、AsmParser、Disassembler 分层；Target 不等于仅注册优化 Pass |
| 构建与新架构 | llvm/CMakeLists.txt、TargetParser/Triple.h、WritingAnLLVMBackend.rst | 区分启用既有后端、构建新目标库、架构 triple 支持和 Clang 前端支持；不手工修改 Targets.def |

所有可运行输入在 [experiments/ch13](../experiments/ch13/runner.py)，最新返回码和检查条件见 [experiments-ch13.json](experiments-ch13.json)。正例覆盖 TableGen 与现有 BPF 代码生成，负例覆盖栈参数拒绝；没有新增可由 llc 执行的 Book 后端，也没有运行目标内核或测量性能。
