# 第 10 章静态校对记录

基准：原书 LLVM 15.0.1；本地 `/opt/llvm-project` 的 LLVM 18.1.8，提交 `3b5b5c1ec4a3095ab096dd780e84d7ab81f3d7ff`。未编译 LLVM，未运行 `llc`、`opt`、LLVM IR/MIR 或书中程序。源码行号以该提交为准；本地 BPF 文件存在修改，相关 TableGen 定义通过 `git show HEAD:路径` 读取，不采用工作区修改作为 LLVM 18 标准行为。

“静态一致”表示算法/语法可由阅读说明，不表示已验证生成结果。书中 MIR、区间、分配顺序、成本和性能数字属于原书实验记录，除明确的文本错误外予以保留，不能当作 LLVM 18.1.8 实测结果。

## 关键实现与修正

| 主题 | 依据 | 判断/修正 |
|---|---|---|
| 默认分配器 | `lib/CodeGen/TargetPassConfig.cpp:1310,1342,1376,1413,1423` | 通用 O0 Fast，优化路径 Greedy，目标可重载；O0 下不能只改 -regalloc=basic，须选择优化分配路径。新增 LLVM18 Mermaid 顺序图；分析依赖不是显式重复执行所有 Pass。 |
| Fast hooks | `TargetPassConfig.cpp:1376` | 新增 `addPostFastRegAllocRewrite`，Fast自身重写；PreRewrite/PostRewrite 是 hooks 不是固定名称 Pass。 |
| Dead/Undef | `DetectDeadLanes.cpp:540`；`ProcessImplicitDefs.cpp:76,90` | dead 定义不保证无需物理寄存器；普通有副作用指令不能因所有 uses undef 删除；物理 IMPLICIT_DEF 找不到本块使用可保留。 |
| PHI正确性 | `PHIElimination.cpp:269,675`；`docs/LangRef.rst` | 正确维护并行 PHI 语义；仅默认避开循环回边等情形，非全部循环内关键边；live-out/live-in 条件原文多处相反。 |
| LiveRegMatrix | `lib/CodeGen/LiveRegMatrix.cpp:104,146,164,186` | 按物理 register-unit 管理区间并区分 regmask/fixed/virtual 干涉；栈槽映射在 VirtRegMap。 |

| StackSlotColoring | `lib/CodeGen/StackSlotColoring.cpp:198,235,348,445` | 基于引用频率累积权重与 StackID、大小、对齐；load 后同寄存器写回同栈槽可去 store，非 store 后 load。 |
| PostRA LICM | `lib/CodeGen/MachineLICM.cpp:430,518,581` | 栈 reload 正是候选；循环中同槽有 store/寄存器 clobber 等会阻止；并非所有不变量都外提。 |
| Basic | `RegAllocBasic.cpp:212,264` | 检查全部别名 regunit 干涉，不可溢出或权重大于当前则拒绝；否则 spill interference，再尝试 spill self；没有全局最优保证。 |
| Greedy | `RegAllocGreedy.cpp:305,483,1569,1956,2410`；`RegAllocEvictionAdvisor.cpp:151` | 区分优先级/权重、evict/split/spill；补 cascade、约束/提示和 last-chance recoloring；本地区间排序非一律按大小。 |

| PBQP归约 | `include/llvm/CodeGen/PBQP/ReductionRules.h` | R1/R2公式按矩阵方向统一；原 C02[0][1]末行应[1][1]；高阶启发式不保证最优，穷举空间 ∏k_i。 |
| PBQP工作集 | `include/llvm/CodeGen/RegAllocPBQP.h:245,428,480` | 保守可分配/不可证明可分配是干涉与选项判定，不是前K/后K变量；比较器先spill cost再degree，与同文件“ratio”注释也不同，应以实现为准。 |
| 图着色 | 概念核对，与 `LiveRegMatrix.cpp`/PBQP形成比较 | degree<K简化保留可着色性，图着色不是无条件最快/最好；COPY边不是干涉边。 |
